# The Story Lab

Interactive Story สำหรับฝึกเขียนภาษาอังกฤษชั้นมัธยมศึกษาปีที่ 5 เปิดด้วย `index.html` ได้ทันที ใช้ HTML, CSS และ JavaScript ในไฟล์เดียว ไม่มีขั้นตอน build ไม่มีบริการหลังบ้าน และไม่มี API key

## กิจกรรมในเว็บ

1. อ่าน **The Library of Unwritten Lives** แล้วเลือกเส้นทาง 2 ระดับเพื่อค้นพบ 4 ตอนจบ
2. คลิกคำศัพท์ในเรื่องเพื่อดูความหมายภาษาไทยและตัวอย่างภาษาอังกฤษ มีคลังตัวอย่าง 30 คำ
3. ดูแผนที่เรื่องเพื่อสังเกตความสัมพันธ์ระหว่างเหตุ ทางเลือก และผลลัพธ์
4. เขียนจุดเริ่มต้น จุดตัดสินใจ และตอนจบ A/B ของตนเอง
5. ใช้คำสั่งสำหรับ AI coach ในบริการ AI ที่ครูอนุญาต แล้วบันทึกเหตุผลในการปรับปรุงงาน
6. ดาวน์โหลดชิ้นงานเป็นไฟล์ `.txt` เพื่อส่งให้ครูหรือเพื่อน

ร่างงานบันทึกใน localStorage ของเบราว์เซอร์บนเครื่องผู้เรียนเท่านั้น ไม่ซิงก์ข้ามเครื่อง ไม่ส่งให้ครู และอาจหายเมื่อผู้ใช้ล้างข้อมูลเบราว์เซอร์ ให้ดาวน์โหลดงานสำรอง การเปิดจากไฟล์และจากเว็บไซต์ใช้พื้นที่บันทึกคนละแห่ง ประวัติการอ่านและช่องตรวจทานจะเริ่มใหม่เมื่อโหลดหน้าอีกครั้ง

## ใช้ประกอบการสอน

ต้นแบบนี้ประยุกต์จากรายงาน **การพัฒนารูปแบบการจัดการเรียนรู้การเขียนภาษาอังกฤษเชิงสร้างสรรค์โดยใช้ Interactive Story ร่วมกับเทคโนโลยี AI สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 5** โดยนายนนกร มังคละศิริ ในไฟล์ `วิจัย.docx` ที่ผู้ใช้ให้มา

สิ่งที่นำมาใช้คือฉากประตูใน Grand Library จากภาคผนวก แนวคิด branching narratives การเสริมคำศัพท์ การใช้ AI เป็นโค้ช และสัดส่วนหมวดประเมิน 30/20/20/20/10 เรื่องและตอนจบในเว็บไซต์แต่งขึ้นใหม่เพื่อสาธิต ไม่ใช่ผลงานนักเรียนหรือหลักฐานการวิจัย และไม่ได้เผยแพร่เอกสารวิจัยต้นฉบับ

- **โปรเจกต์:** เป้าหมายคำศัพท์ใหม่อย่างน้อย 30 คำ ตามเนื้อหารายงาน
- **แนวโจทย์หลังเรียน:** 300–400 คำรวมทุกเส้นทาง และคำศัพท์อย่างน้อย 15 คำ ตามคำชี้แจงภาคผนวก เว็บนี้เป็นพื้นที่ฝึก ไม่ได้จับเวลา 60 นาทีหรือใช้ควบคุมการสอบ
- ตัวนับคำศัพท์ตรวจเฉพาะคำไม่ซ้ำที่ตรงกับคลังตัวอย่าง 30 คำ ไม่ครอบคลุมคำผัน ไม่พิสูจน์ว่าคำนั้นใหม่สำหรับผู้เรียน และไม่ตรวจความถูกต้องตามบริบท
- ไม่มีการให้คะแนนอัตโนมัติ ครูต้องพิจารณาชิ้นงานจริง รายงานต้นฉบับมีเกณฑ์ระดับคะแนนหลายรูปแบบ เว็บจึงนำมาใช้เฉพาะหมวดและน้ำหนักที่สอดคล้องกัน
- คำสั่ง AI เป็นข้อความที่เตรียมไว้ให้คัดลอก เว็บไม่ได้เรียก AI หรือสร้างข้อเสนอแนะสด

## GitHub Pages

วาง `index.html`, `.nojekyll` และ README นี้ที่ราก repository จากนั้นเลือก **Settings → Pages → Deploy from a branch → main → /(root) → Save** เมื่อ GitHub เผยแพร่เสร็จ หน้า Pages จะแสดงลิงก์เว็บไซต์

ไฟล์ `.nojekyll` ให้ GitHub เผยแพร่ไฟล์ static โดยตรง สามารถแก้ไขเนื้อเรื่องและคำศัพท์ในตัวแปร `STORY` และ `VOCAB` ภายใน `index.html` ได้ ควรรักษา ID ของแต่ละฉากและปลายทางใน `choices` ให้ตรงกัน

## การเข้าถึง

รองรับจอเล็ก ปุ่มคำศัพท์ใช้คีย์บอร์ดได้ มีป้ายกำกับช่องเขียน และแท็บรองรับปุ่มลูกศรซ้าย/ขวา Home และ End การอ่านเรื่องและเขียนงานทำได้แบบออฟไลน์เมื่อดาวน์โหลดไฟล์ไว้แล้ว การใช้ AI ภายนอกต้องใช้อินเทอร์เน็ต
